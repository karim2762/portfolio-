Kexer Portfolio is a modern personal portfolio website designed to showcase projects, skills, and experience through elegant UI, smooth animations, and immersive 3D interactions.

The website is optimized for performance, accessibility, and responsiveness across all devices.

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/karim2762/portfolio-.git
```

Navigate to the project

```bash
cd portfolio-
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm run dev
```

Build production

```bash
npm run build
```
